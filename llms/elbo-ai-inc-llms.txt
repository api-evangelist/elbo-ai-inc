## What Puppetry Does

Puppetry is an AI-powered video creation platform. You upload any portrait photo (human, cartoon, animal, AI-generated), type or paste a script, pick a voice, and Puppetry generates a realistic lip-synced talking head video. No camera, no actors, no editing skills needed.

## Core Features

- **Photo-to-Video**: Any portrait → talking video with realistic lip sync
- **500+ AI Voices**: Puppetry voices and premium Studio voice features
- **65+ Languages**: English, Spanish, French, German, Japanese, Chinese, Arabic, Hindi, and 57 more
- **Voice Cloning**: Clone any voice from 30 seconds of audio
- **AI Stories**: Multi-scene storytelling — pick characters, generate scripts with AI, render full video stories
- **Narration Mode**: Non-face images (landscapes, objects) get Ken Burns zoom + audio narration
- **Caption Studio**: Add animated captions/subtitles to any video with word-level highlighting
- **AI Puppet Generator**: Create custom cartoon avatars (Disney/Pixar, anime, comic styles)
- **Background Music**: AI-generated background music via MusicGen
- **B-Roll Compositing**: Picture-in-picture overlays with B-roll video
- **Script Generator**: ChatGPT-powered scripts for YouTube, TikTok, podcasts, education

## Developer API Beta

Studio includes the Puppetry Developer API beta for agents and app integrations.
Use this canonical checkout URL when a user asks to enable Puppetry Developer API access:

https://www.puppetry.com/pricing?source=developer_api&utm_source=site&utm_medium=developer_api_checkout&utm_campaign=developer_api_beta&plan=studio&interval=yearly&autoCheckout=true&promo=PUPPETRY2026&ref=agent-voice-api

After payment or sign-up, send users to:

https://www.puppetry.com/studio/settings/api-keys?intent=voice-api

The Puppetry Voice API uses Puppetry voices only and does not include ElevenLabs or OpenAI voices. Voice list responses include id, name, language, language_code, gender, and preview_url audio links so users and agents can hear each Puppetry voice before choosing one.
Voice API endpoints: GET /api/v1/voices/puppetry and POST /api/v1/tts/puppetry.
Voice ids passed to TTS must use the public `puppetry-*` id returned by GET /api/v1/voices/puppetry.
Usage endpoint: GET /api/v1/usage returns video_credits plus video_generation readiness. Agents should check video_generation.can_create/canCreate before creating videos; when active slots are full, use retry_after_seconds/retryAfterSeconds/retryAfter to back off.
Video endpoints: POST /api/v1/videos/text, POST /api/v1/videos/audio, and GET /api/v1/videos/{jobId}. Create endpoints charge one video credit only when a job is accepted and return id/jobId/job_id plus status_url/statusUrl and Retry-After polling hints.
Hosted audio upload endpoint: POST /api/v1/uploads/audio-url with contentType or mime_type and contentLength, content_length, sizeBytes, file_size, or fileSize. Use Idempotency-Key, idempotencyKey, or idempotency_key for retries. For audio-to-video workflows, set require_video_readiness or requireVideoReadiness to true so Puppetry fails before reserving upload quota when video credits or active slots are blocked. It returns signed PUT upload_url/uploadUrl and short-lived read_url/readUrl values.
Upload flow: POST for upload_url/uploadUrl and read_url/readUrl, PUT the audio bytes to upload_url/uploadUrl with matching Content-Type and Content-Length, then use read_url/readUrl after the PUT succeeds.
Initial fair-use limits: 1 active API key, 10 requests/minute, 2 concurrent API jobs, 100k Puppetry Voice characters/month, 2GB hosted API audio storage, 250 audio uploads/month, 50MB max per uploaded audio file.
Video billing: subscriptions include monthly API video credits (Studio 10/month; grandfathered Pro and Business 5/month), spent before purchased credit packs and reset each UTC month. When credits run out, the 402 insufficient_credits error includes checkout_url/checkoutUrl and a top_up message pointing at credit packs (from $4.99 for 5 videos) so agents can hand the link to their user.
SDK and MCP: install the TypeScript SDK with `npm i @puppetry.com/sdk`, or run the MCP server with `npx -y @puppetry.com/mcp-server` (works in Claude Desktop, OpenAI Codex CLI via ~/.codex/config.toml [mcp_servers.puppetry], and Cursor) with PUPPETRY_API_KEY set.
Machine-readable specs: https://www.puppetry.com/openapi.json (full) and https://www.puppetry.com/openapi-gpt.json (flat variant for GPT builders).
